# ConnectSphere — Social Media Platform

A full-stack social media platform developed as part of the **CodeAlpha Full Stack Development Internship — Task 2**.

ConnectSphere is designed as a modern, responsive social networking application where users can create profiles, publish posts, interact through likes and comments, follow other users, and personalize their experience using light and dark themes.

## ⚙️ Getting Started

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Git
- VS Code

### 1. Clone the Repository

```bash
git clone https://github.com/gmpragna11-max/CodeAlpha_SocialMediaPlatform.git
```

### 2. Navigate to the Project

```bash
cd CodeAlpha_SocialMediaPlatform
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Visit:

```text
http://localhost:3000
```

If port `3000` is already occupied, Next.js will automatically use another available port.

## 🎨 Light & Dark Mode

ConnectSphere provides a dedicated theme toggle that allows users to switch between:

**☀️ Light Mode**  
A clean and bright interface optimized for normal lighting conditions.

**🌙 Dark Mode**  
A dark interface designed for comfortable viewing in low-light environments.

The selected theme is stored locally so the user's preference is preserved.
